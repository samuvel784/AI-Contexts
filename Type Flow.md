# Type Flow

## Website Overview

### Project Name
**Type Flow** (also styled as "TypeFlow")

### Website URL
https://typeflow-rouge.vercel.app

### One-Sentence Description
Type Flow is a free, privacy-first typing practice platform that helps users improve typing speed and accuracy through structured exercises, real-time metrics, and a distraction-free interface — with no account or sign-up required.

### Website Purpose
Type Flow exists to help people become faster, more accurate typists through regular practice. It solves the problem of finding a clean, focused typing practice tool that respects user privacy — no accounts, no tracking, no data collection. Just typing.

### Who Is This For?
- Students looking to improve typing skills
- Beginners learning touch typing
- Professionals wanting to increase productivity
- Typing enthusiasts aiming for higher WPM
- Anyone who wants to practice typing regularly without creating an account

### Main Value
- **Completely free** — no paid plans or subscriptions
- **No account required** — start typing immediately
- **Privacy-first** — all calculations happen in your browser
- **No distractions** — clean, minimal interface
- **Instant feedback** — real-time WPM and accuracy stats

## Feature Documentation

### WPM (Words Per Minute) Tracking

**What It Does:** Measures and displays your typing speed in real-time based on the standard measurement of words per minute.

**How To Access It:** WPM is automatically shown during any practice session on the Practice page, Custom page, or Challenges page.

**How To Use It:** Simply start typing in any practice session — the WPM counter updates in real-time as you type.

**Common Use Cases:**
- Tracking speed improvement over time
- Setting personal speed goals
- Comparing performance across different text difficulties

**Tips:** Focus on accuracy first; speed will naturally improve. Try to maintain consistent WPM throughout the entire session rather than peaks.

**How WPM Is Calculated:** WPM is measured using the standard formula: total characters typed ÷ 5 (standard word length) ÷ time in minutes. This is gross WPM — it counts all keystrokes including errors. For example, typing 150 characters in 1 minute = 30 WPM.

**Common Problems:** WPM may fluctuate during a session. This is normal — consistency improves with practice.

**Solutions:** If WPM seems unusually low, check that you're typing without looking at the keyboard. Looking down disrupts flow.

---

### Accuracy Percentage

**What It Does:** Shows the percentage of correctly typed keystrokes versus total keystrokes during a session.

**How To Access It:** Accuracy is displayed alongside WPM during any practice session.

**How To Use It:** Monitor your accuracy percentage as you type. Higher accuracy means fewer errors.

**Common Use Cases:**
- Ensuring you're not sacrificing accuracy for speed
- Identifying problem keys or patterns
- Measuring improvement over time

**Tips:** Aim for 95%+ accuracy before trying to increase speed. Speed is a byproduct of accuracy.

**Common Problems:** Low accuracy percentage despite feeling like you're typing correctly.

**Solutions:** Slow down and focus on proper finger placement from the home row. Practice the specific characters you tend to miss.

---

### Error Highlighting

**What It Does:** Immediately highlights incorrect keystrokes in the displayed text, giving you visual feedback on mistakes. Correct characters appear in one color (typically green/teal), errors appear in a contrasting color (typically red), and the current character you need to type is highlighted with a distinct marker.

**How To Access It:** Automatic during any practice session.

**How To Use It:** When you see an error highlighted, note which key you missed and continue typing. Don't stop or try to correct it — backspace is disabled.

**Common Use Cases:**
- Learning which keys you frequently mistype
- Building awareness of finger placement errors
- Improving precision through visual feedback

**How Error Handling Works:** When you press a wrong key, the incorrect character appears in the error color but the cursor does not advance to the next expected character — it waits for the correct keystroke. The incorrect character is still counted as an error in your accuracy. You cannot skip past an error by typing the next character; you must type the correct character to proceed.

**Tips:** Use error highlighting as a learning tool. Notice patterns in your errors (e.g., common letter pairs, certain finger reaches).

**Common Problems:** Seeing many errors on unfamiliar words or symbols.

**Solutions:** Practice on easier difficulty levels first, then progress to harder texts with symbols and numbers.

---

### Time-Based Tests

**What It Does:** Sets a fixed time limit (30 seconds or 60 seconds) for your typing session.

**How To Access It:** Available on the Practice page (/practice) where you can select the duration before starting.

**How To Use It:** Select 30s or 60s before starting a practice session. The timer begins when you press the first key.

**Common Use Cases:**
- Short focused practice sessions
- Benchmarking speed and accuracy under time pressure
- Daily warm-up exercises

**Tips:** Use 30-second tests for warm-ups and 60-second tests for more comprehensive assessment.

**What Happens When Time Runs Out:** The session ends immediately when the timer reaches zero. Your final stats (WPM, accuracy, error count) are displayed based on what you typed up to that point. You do not need to finish the entire passage.

**What Happens When You Finish Early:** If you complete the entire passage before the timer ends, the session stops automatically. Your final stats are based on the completed text.

**Common Problems:** Feeling rushed by the timer.

**Solutions:** Focus on steady, consistent typing rather than trying to type faster than comfortable. Speed will increase naturally.

### No Backspace Mode

**What It Does:** Disables the backspace/delete key during typing sessions. Every keystroke counts.

**How To Access It:** This mode is active by default in practice sessions on Type Flow.

**How To Use It:** Simply type normally. If you make an error, you cannot erase it — continue typing the rest of the text correctly.

**Common Use Cases:**
- Building typing precision
- Breaking the habit of correcting every mistake
- Simulating real-world typing where you must keep moving forward

**Tips:** Embrace mistakes as learning opportunities. The visual error feedback helps you improve for next time.

**Common Problems:** Frustration from not being able to fix errors.

**Solutions:** Shift your mindset — the goal is to train accuracy, not perfection in a single pass.

### Problem: Typing Engine Not Loading

**Possible Causes:**
- Slow internet connection
- Browser compatibility issue
- JavaScript disabled in browser
- Ad blocker interfering with page scripts

**Solution:**
1. Refresh the page (F5 or Ctrl+R).
2. Check your internet connection.
3. Enable JavaScript in your browser settings.
4. Try a different browser (Chrome, Firefox, Edge, or Brave recommended).

**Possible Causes:**
- JavaScript not fully loaded
- Browser extension interference

**Solution:**

3. If the timer still doesn't start, refresh the page and try again.
