## Troubleshooting Guide

### Problem: Site Won't Load

**Possible Causes:**
- Internet connection issue
- Vercel hosting temporary downtime
- Browser cache issue
- URL typed incorrectly

**Solution:**
1. Check your internet connection
2. Try refreshing the page (Ctrl+R or Cmd+R)
3. Clear your browser cache and try again
4. Try the alternate URL: `https://samuvel-portfolio.vercel.app`
5. Try opening in a different browser
6. Wait a few minutes and try again — Vercel hosting is generally reliable

---

### Problem: Page Looks Broken or Elements Missing

**Possible Causes:**
- Slow internet causing assets to not load
- Browser not supported (very old browser)
- JavaScript disabled in browser
- Temporary glitch

**Solution:**
1. Refresh the page
2. Check that JavaScript is enabled in your browser settings
3. Try a modern browser (Chrome, Firefox, Edge, Safari)
4. Clear your cache and reload

---

### Problem: Email Link Doesn't Open

**Possible Causes:**
- No email client configured on your device
- Browser not set up to handle mailto: links
- Popup blocker interfering

**Solution:**
1. Manually send an email to: **samuvel072@gmail.com**
2. Use the subject line: "✨ Message from Portfolio"
3. Try a different browser
4. Check if your computer has a default email program set

---

### Problem: External Links Not Opening

**Possible Causes:**
- Popup blocker preventing new tabs
- Browser security settings
- Temporary site downtime for the linked project

**Solution:**
1. Check if your browser is blocking pop-ups — allow them for this site
2. Try right-clicking the link and selecting "Open in new tab"
3. The linked projects (TypeFlow, Special Wishes, etc.) are hosted on separate domains — check if they're accessible directly
4. If a specific project link doesn't work, it may be temporary — try again later

---

### Problem: Slow Performance or Lag

**Possible Causes:**
- Low-end device struggling with animations (canvas particles, 3D tilt, custom cursor)
- Many browser tabs open
- Slow internet connection

**Solution:**
1. The site has a `prefers-reduced-motion` setting — if your device/browser supports it, animations will automatically reduce
2. Close other browser tabs to free up resources
3. The custom cursor and canvas effects are cosmetic — they don't affect functionality

---

### Problem: Mobile Issues

**Possible Causes:**
- Screen too small for certain layouts
- Touch interactions differ from mouse
