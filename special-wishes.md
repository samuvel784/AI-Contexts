# Special Wishes — Full Project Guide

## What is Special Wishes?
Special Wishes is a greeting card creator web app built by Samuvel (Sam). Users can create personalized greeting cards for any occasion and share them with others via a unique link.

## Live Link
https://special-wishes-kohl.vercel.app

## Tech Stack
- Next.js 14
- Tailwind CSS
- Framer Motion (animations)
- Vercel (deployment)

## How to Create a Greeting Card (Step by Step)
1. Visit https://special-wishes-kohl.vercel.app
2. Click the "Create Card" button on the homepage
3. Choose an occasion from the list (Birthday, Love, Friendship, Congratulations, etc.)
4. Enter the recipient's name in the name field
5. Type your personal message in the message box
6. Click the "Generate Card" button
7. Your personalized card will appear with a beautiful animation
8. Click "Copy Link" to get a shareable URL
9. Send the link to anyone — they can view the card in their browser

## How to Share a Card
- Every generated card gets a unique URL
- Copy the link from the share button
- Send it via WhatsApp, Instagram, email, or any messaging app
- The recipient opens the link and sees the animated greeting card
- No account or login is required to view a card

## How the Greeting Animation Works
- The card entrance uses a scale(0.8) to scale(1) animation powered by Framer Motion
- The greeting text fades in line by line with a 0.3 second delay between each line
- The background uses a soft gradient that matches the occasion color theme
- Built with Framer Motion's motion.div using initial, animate, and transition props

## Features
- Multiple occasion types (Birthday, Love, Friendship, Congratulations, Thank You)
- Personalized recipient name on the card
- Custom message support
- Unique shareable link for every card
- Beautiful animated card entrance
- Mobile responsive design
- No login required

## Common User Questions

Q: Do I need an account to create a card?
A: No, you can create and share cards without signing up.

Q: Can I edit the card after creating it?
A: You need to create a new card with the updated message.

Q: Does the card link expire?
A: No, the card link is permanent once created.

Q: Can I send the card to multiple people?
A: Yes, just share the same generated link with as many people as you want.

Q: Is Special Wishes free to use?
A: Yes, it is completely free.

Q: What occasions are supported?
A: Birthday, Love, Friendship, Congratulations, and Thank You.
